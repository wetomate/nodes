# Security policy

## Supported versions

Security fixes target the latest published version of each package. Maintainers may provide fixes for older versions when the impact and compatibility risk justify it.

## Reporting a vulnerability

Do not report vulnerabilities, exposed credentials, or exploit details in a public issue.

Use [GitHub private vulnerability reporting](https://github.com/wetomate/nodes/security/advisories/new) to send the affected package and version, reproduction steps, impact, and any suggested mitigation. Remove real credentials, personal data, and unrelated secrets from the report.

Maintainers will acknowledge the report, assess its impact, coordinate a fix and release where necessary, and credit reporters who want attribution. Please allow a reasonable remediation period before public disclosure.
